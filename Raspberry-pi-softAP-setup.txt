# Raspberry Pi Local SoftAP Setup Guide
### CS Project — Landmine Detection System

---

## What you are building

```
ESP32-CAM
├── Joins Pi's WiFi network (badboynet)
├── Captures JPEG frames
├── Authenticates with hashed token
└── Sends frames over WebSocket
          ▼
Raspberry Pi
├── Creates WiFi network (badboynet)
├── IP: 192.168.4.1
├── Receives JPEG frames
├── Runs frames through YOLOv8
└── Sends detection result back
          ▼
ESP32-CAM
└── Receives result e.g. "landmine: 94%" or "clear"
```

No internet. No router. Fully standalone.

---

## How this works

Modern Raspberry Pi OS uses **NetworkManager** to manage all network interfaces. It can create a WiFi hotspot directly — handling the access point, DHCP, and static IP all internally. We use a single command line tool called `nmcli` to configure it. No config files, no hostapd, no dnsmasq.

---

## Performance expectations

| Pi Model | YOLOv8 inference speed |
|---|---|
| Pi 3 | ~3–8 seconds per frame |
| Pi 4 | ~0.5–1 second per frame |
| Pi 5 | ~0.3 seconds per frame |

For landmine detection this is fine — you are not moving fast, so capture → wait → result → move forward is a workable loop even on a Pi 3.

## Step 2 — Create the hotspot

These four commands are the entire network setup:

```bash
sudo nmcli con add type wifi ifname wlan0 con-name pihotspot autoconnect yes ssid badboynet
sudo nmcli con modify pihotspot 802-11-wireless.mode ap 802-11-wireless.band bg ipv4.method shared ipv4.addresses 192.168.4.1/24
sudo nmcli con modify pihotspot wifi-sec.key-mgmt wpa-psk wifi-sec.psk "badboy123"
sudo nmcli con up pihotspot
```

What each line does:

| Command | What it does |
|---|---|
| `con add` | Creates a new WiFi connection called pihotspot |
| `con modify` (first) | Sets AP mode, gives Pi the static IP 192.168.4.1 |
| `con modify` (second) | Sets WPA2 password |
| `con up` | Activates the hotspot |

`autoconnect yes` means the hotspot starts automatically on every reboot.

---

## Step 3 — Verify the hotspot

Check it is active:
```bash
nmcli con show pihotspot | grep STATE
```
Expected output: `GENERAL.STATE: activated`

Check the Pi has the correct IP:
```bash
ip addr show wlan0
```
You should see `192.168.4.1` in the output.

On your phone or laptop, check that `badboynet` appears in the WiFi list. Connect to it with password `badboy123`, then SSH back into the Pi:
```bash
ssh badboii@192.168.4.1
```

If that works, you are done with home WiFi forever.

## Step 5 — Pre-compute the auth token hash

The ESP32 authenticates by sending a SHA256 hash of a shared secret. The raw password never travels over the air.

Run this on the Pi to generate the hash:
```bash
python3 -c "import hashlib; print(hashlib.sha256('badboy123'.encode()).hexdigest())"
```

Copy the output — you will need it in the ESP32 code. It will look something like:
```
a665a45920422f9d417e4867efdc4fb8a04a1f3fff1fa07e998e86f7f7a27ae3
```

## Step 6 — Save the WebSocket server

```bash
cat > ~/Coolbadboienv/server.py << 'EOF'
import asyncio
import hashlib
import websockets
import numpy as np
import cv2
from ultralytics import YOLO

model = YOLO("yolov8n.pt")  # replace with your trained model path

SECRET_HASH = hashlib.sha256("badboy123".encode()).hexdigest()

async def handler(websocket):
    # Step 1 — authenticate
    try:
        token = await websocket.recv()
        if hashlib.sha256(token.encode()).hexdigest() != SECRET_HASH:
            print("Rejected: wrong token")
            await websocket.close()
            return
    except websockets.exceptions.ConnectionClosed:
        return

    print("ESP32 authenticated and connected")

    # Step 2 — receive frames and run inference
    try:
        async for message in websocket:
            # Decode incoming JPEG bytes
            jpg = np.frombuffer(message, dtype=np.uint8)
            frame = cv2.imdecode(jpg, cv2.IMREAD_COLOR)

            if frame is None:
                await websocket.send("ERROR: bad frame")
                continue

            # Run YOLOv8
            results = model(frame)

            # Build result string
            detections = []
            for box in results[0].boxes:
                label = model.names[int(box.cls)]
                confidence = float(box.conf)
                detections.append(f"{label}: {confidence:.0%}")

            result = ", ".join(detections) if detections else "clear"
            print(f"Result: {result}")
            await websocket.send(result)

    except websockets.exceptions.ConnectionClosed:
        print("ESP32 disconnected")

async def main():
    async with websockets.serve(handler, "0.0.0.0", 8080, max_size=10_000_000):
        print("YOLOv8 WebSocket server running on port 8080")
        await asyncio.Future()

asyncio.run(main())
EOF
```

## Step 8 — Flash the ESP32

Replace `YOUR_HASH_HERE` with the hash you generated in Step 5:

```cpp
#include <WiFi.h>
#include <WebSocketsClient_Generic.h>
#include "esp_camera.h"

const char* ws_host    = "192.168.4.1";
const uint16_t ws_port = 8080;
const char* ws_path    = "/";

// Paste your hash from Step 5 here
const char* TOKEN = "YOUR_HASH_HERE";

WebSocketsClient webSocket;
bool authenticated = false;

void connectToWiFi() {
  Serial.println("[WiFi] Connecting to Pi...");
  WiFi.mode(WIFI_STA);
  WiFi.begin("badboynet", "badboy123");

  while (WiFi.status() != WL_CONNECTED) {
    Serial.print(".");
    delay(1000);
  }

  Serial.println("\n[WiFi] Connected!");
  Serial.print("[WiFi] ESP32 IP: ");
  Serial.println(WiFi.localIP());
}

void webSocketEvent(WStype_t type, uint8_t* payload, size_t length) {
  switch (type) {

    case WStype_CONNECTED:
      Serial.println("[WS] Connected — sending token");
      webSocket.sendTXT(TOKEN);  // send hash, not raw password
      authenticated = true;
      break;

    case WStype_DISCONNECTED:
      Serial.println("[WS] Disconnected");
      authenticated = false;
      break;

    case WStype_TEXT:
      // Detection result coming back from Pi
      Serial.print("[Result] ");
      Serial.println((char*)payload);
      break;

    case WStype_ERROR:
      Serial.println("[WS] Error");
      break;
  }
}

void captureAndSend() {
  camera_fb_t* fb = esp_camera_fb_get();
  if (!fb) {
    Serial.println("[CAM] Capture failed");
    return;
  }

  Serial.println("[CAM] Sending frame...");
  webSocket.sendBIN(fb->buf, fb->len);  // send raw JPEG bytes
  esp_camera_fb_return(fb);
}

void setup() {
  Serial.begin(115200);
  delay(1000);

  // Camera init goes here (depends on your ESP32-CAM board)

  connectToWiFi();
  webSocket.begin(ws_host, ws_port, ws_path);
  webSocket.onEvent(webSocketEvent);
  webSocket.setReconnectInterval(3000);

  Serial.println("[Setup] Complete");
}

void loop() {
  webSocket.loop();

  // Send a frame every 2 seconds if connected and authenticated
  static unsigned long lastCapture = 0;
  if (millis() - lastCapture > 2000 && authenticated) {
    lastCapture = millis();
    captureAndSend();
  }
}
```

## Security summary

| Layer | Protection |
|---|---|
| WPA2 on badboynet | Stops unknown devices joining the network |
| SHA256 hashed token | Raw password never sent over the air |
| No internet exposure | Network is fully isolated, no external attack surface |

---

## Troubleshooting

| Problem | Fix |
|---|---|
| `badboynet` not visible | Run `nmcli con show pihotspot` — check STATE is activated |
| Hotspot gone after reboot | Run `sudo nmcli con modify pihotspot autoconnect yes` |
| ESP32 rejected by server | Token mismatch — re-run Step 5 and update ESP32 code |
| Frame returns `ERROR: bad frame` | Camera not initialised correctly on ESP32 |
| YOLOv8 crashes on Pi 3 | Try `yolov8n.pt` (nano model) — smallest and fastest |
| Server not running | Check tmux: `tmux attach -t websocket` |
